Inspired by Karpathy's autoresearch

An ML researcher that works the night shift.

Point an AI agent at a CSV and go to sleep. It edits one training file, runs the experiment, keeps the change with a git commit if the metric improved, reverts it if it didn't, and goes again.

The loop

Change one thing. Measure. Keep or undo.

The orchestrator is fixed; only the agent's edits change. Git is the lab notebook, so the history of train.py is a list of things that worked.

01 · prepare

Clean once

Duplicates, imputation, encoding, scaling and SMOTE run once into train, validation and test splits. These critical steps can't be skipped.

02 · experiment

Train and score

The agent edits get_model() and the notes string, then runs cross-validated training under a time limit.

03 · decide

Commit or revert

Better than the best score? Commit. Otherwise revert. After 3 misses in a row, it suggests changing preprocessing instead.

Guardrails

One file to change. Everything else is locked.

The agent prompt is short and strict, so a night of unattended runs stays reviewable in the morning.

  • src/train.pyThe only file the agent may modify.
  • src/prepare.pyRead only: the preprocessing pipeline.
  • run_experiment.pyRead only: train, log, compare, commit or revert.
  • best_scores.jsonWhat has been tried and the current best, read before every move.
  • uv addNew packages go through uv. Never pip.
  • strategySimple models first, then boosting, then voting and stacking ensembles.
Configure

Describe the task in program.md.

Dataset, target, metric, preprocessing choices and free-form instructions like "only tree-based models" or "go wild".

When you're happy, promote the best run from the MLflow registry with select_model.py --rank 1.

dataset:
  path: data/house_prices.csv
  target_column: Price (in rupees)
  task_type: auto          # classification | regression
metric:
  primary: auto            # f1_weighted | rmse | r2 …
preprocessing:
  imputer: median          # mean | knn | iterative
  encoder: label_onehot    # ordinal | target
  scaler: standard         # minmax | robust | maxabs
mlflow:
  experiment_name: agentml_experiment
  top_n_models: 5
constraints:
  cv_folds: 10
  max_training_time: 300   # seconds
Start

Drop in a CSV. Wake up to a better model.

terminal
uv venv && uv sync
# put your CSV in data/ and fill in program.md
python src/run_experiment.py
# then hand the loop to Claude Code or another agent
